# Piloter Allez Robert avec BikeControl (Zwift Play, Click, Ride…)

Deux façons d'utiliser les manettes Zwift :

1. **En direct (sans BikeControl)** : Réglages → Matériel → adaptateurs expérimentaux → « Zwift Click v1 / v2,
   Play, Ride ». Le jeu se connecte lui-même en Bluetooth aux manettes (boutons uniquement ; le Click v2
   gauche et le Ride v2 doivent avoir été déverrouillés une fois par l'appli Zwift).
2. **Par BikeControl** : BikeControl se connecte aux manettes et envoie des touches du clavier à la fenêtre
   active. Créer un profil « Allez Robert » avec la table ci-dessous. Garder l'adaptateur Zwift du jeu
   **coupé** dans ce cas : une manette Bluetooth ne se connecte qu'à une appli à la fois.

| Action dans le jeu | Touche à envoyer | Bouton conseillé (Zwift Play) |
| --- | --- | --- |
| Pignon plus dur | Flèche haut | droite : + |
| Pignon plus facile | Flèche bas | droite : − |
| Plateau plus grand / plus petit | Page haut / Page bas | droite : Y / gauche : Y |
| Se décaler à gauche / à droite (maintenir) | Flèche gauche / Flèche droite | gauche : ◀ / ▶ |
| Choisir la route au carrefour (monde ouvert) | Flèche gauche / Flèche droite | gauche : ◀ / ▶ |
| Faire demi-tour | U | gauche : B |
| Groupe : allure + / − | ] / [ | droite : A / gauche : A |
| Groupe : « ralentissez » / « attendez-moi » | R / K | gauche : ↑ / ↓ |
| Changer de formation du groupe | F | droite : B |
| Changer de caméra | C | droite : Z |
| Regarder derrière (maintenir) | X | gauche : Z |
| Photo | P | — |
| Masquer l'interface | H | — |
| Pause / menu | Échap ou Espace | gauche : bouton de côté |
| Musique lecture / suivante | B / N | — |
| Couper le son | M | — |

Les touches du jeu sont lues sur toute la fenêtre (pas besoin de cliquer dans la vue 3D), sauf quand un
champ de saisie a le curseur. Dans l'application Windows, la fenêtre d'Allez Robert doit être au premier
plan : c'est elle qui reçoit les touches envoyées par BikeControl.
